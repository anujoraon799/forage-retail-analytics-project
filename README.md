# 🛒 Retail Analytics & Store Trial Analysis

## 🔍 Overview

This project is part of the Quantium Retail Analytics Virtual Experience (Forage), where I analyzed retail transaction data and evaluated the impact of store layout changes using data analysis and statistical testing.

---

## 🎯 Objectives

* Understand customer purchasing behavior
* Identify key sales drivers and customer segments
* Evaluate trial store performance using control store comparison

---

## 🛠️ Tools Used

* Python (Pandas, NumPy)
* Matplotlib & Seaborn
* Statistical Testing (T-test)

---

## 📊 Task 1: Sales & Customer Analysis

* Cleaned and processed transaction data (~260K rows)
* Removed outliers and irrelevant products
* Extracted features like pack size and brand
* Analyzed:

  * Customer segments
  * Sales contribution
  * Product preferences

### 🔑 Insights

* Older Families (Budget) contribute highest sales
* Most purchases are in 175g–180g pack sizes
* Top brands: Kettle, Smiths, Doritos

---

## 🧪 Task 2: Trial Store Analysis

* Trial stores: 77, 86, 88
* Selected control stores using correlation
* Compared sales before and after trial

### 📈 Key Results

* Sales increased in trial stores
* Increase driven by more customers (not frequency)
* Statistical test (p > 0.05) → not significant

---

## 📌 Conclusion

Trial layout shows potential but requires further testing before business rollout.
