# 🛒 Retail Analytics & Store Trial Analysis

## 🔍 Overview

This project is part of the Quantium Retail Analytics Virtual Experience (Forage), where I analyzed retail transaction data (~260K rows) and evaluated the impact of store layout changes using data analysis and statistical testing.

---

## 🎯 Objectives

* Understand customer purchasing behavior
* Identify key sales drivers and customer segments
* Evaluate trial store performance using control store comparison

---

## 🛠️ Tools & Technologies

* Python (Pandas, NumPy)
* Data Visualization (Matplotlib, Seaborn)
* Statistical Testing (T-test)

---

## 📊 Task 1: Sales & Customer Analysis

* Performed data cleaning and preprocessing
* Removed outliers and irrelevant products (e.g., salsa items)
* Engineered features such as **PACK_SIZE** and **BRAND**

### 🔑 Key Insights

* 👨‍👩‍👧‍👦 Older Families (Budget) generate highest sales
* 📦 Most purchases are in **175g–180g pack sizes**
* 🏆 Top brands: **Kettle, Smiths, Doritos**
* 📈 Sales driven more by **customer count** than purchase frequency

---

## 🧪 Task 2: Trial Store Analysis (A/B Testing)

* Trial stores: **77, 86, 88**
* Control stores selected using **correlation analysis**
* Compared pre-trial vs trial performance

### 📈 Key Results

* 📊 Sales increased in trial stores
* 👥 Growth driven by **more customers**, not frequency
* ⚠️ Statistical test (p > 0.05) → results not statistically significant

---

## 📌 Business Conclusion

The new store layout shows potential for increasing sales, but results are not statistically significant. Further testing is recommended before full-scale implementation.
